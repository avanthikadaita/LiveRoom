# Generic fallback models

One procedural model per allowlisted category, generated by `python -m scripts.make_generic_assets`. Written for FitCheck and released CC0.

Used only when every image-to-3D provider fails or is out of quota. Items that use them are marked `is_approx_model = true` and the UI shows an "approx model" badge. They are still scaled to the listing's real height, so the footprint in AR is honest even when the shape is generic.
